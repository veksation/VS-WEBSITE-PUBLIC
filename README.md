# Vex & Shell public website

Static public site for GitHub Pages. All local URLs are relative to this folder.

## Publishing

Push this folder to the public repository. In Settings → Pages, select
Deploy from a branch, your publishing branch, and /(root).
The .nojekyll file serves these static files directly.

## Editing

Edit descriptions in js/showcase-content.js; links in js/config.js.
Everything in this repository is public, including JavaScript data and images.
Concealed artwork is stored as static black vector silhouettes with generic names.
Only four 30-second soundtrack previews are included.
The contact form uses Web3Forms' public client access key, not a private API token.
